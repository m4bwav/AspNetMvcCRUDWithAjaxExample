# Security policy

This repository is example ASP.NET MVC code from 2014. It isn't maintained and its dependencies are years out of date, so don't deploy it or copy it into production as it is.

## Reporting a problem

You can still open an issue or a pull request and I'll take a look, though a fix isn't promised. If something shouldn't be public (a password or token committed to the repository, for example), open the repository's **Security** tab and choose **Report a vulnerability** instead. Only the maintainer sees those reports.

## Supported versions

None. The code is kept for reference.
